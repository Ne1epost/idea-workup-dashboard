# Дашборд проработки идей — «От идеи до проекта»

Одностраничный дашборд мультиагентной системы проработки идей (idea-workup u2).

## Что показывает

- **Конвейер проработки** — 9 этапов и 4 гейта с нормами по времени; клик по идее подсвечивает её позицию на конвейере.
- **Портфель идей** — статусы, ценность, трудоёмкость, следующий шаг по каждой идее.
- **Агентная сеть u2** — Оркестратор, Аналитик идеи, Критик, Владелец эффекта.
- **Журнал решений** — записи в формате «было → стало → причина».

## Стек

Чистый HTML/CSS/JS, один файл `index.html`, без сборки и зависимостей. Шрифты: JetBrains Mono + Inter (Google Fonts).

  <a href="https://ne1epost.github.io/idea-workup-dashboard/">Открыть демо</a>

Ссылка на демо заработает после включения GitHub Pages (Settings → Pages → Deploy from branch → main → /root).
